# Superstore Sales Analysis – Power BI Dashboard

## 📊 Project Overview

An interactive Power BI dashboard built to analyze sales and profitability
across regions, categories, products, and business segments.

The dashboard provides a consolidated view of key sales KPIs and helps
identify regional performance, category profitability, and product-level
profit trends.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Compare sales across regions
- Evaluate category-wise profit contribution
- Analyze profit margins by category
- Identify top-performing products by profit
- Examine the relationship between sales and profit

## 🛠️ Tools & Techniques

- Power BI
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization
- KPI Analysis

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Total Sales | 112K |
| Order Count | 263 |
| Total Profit | 10K |
| Profit Margin | 11.19% |

## 📈 Dashboard Analysis

### Regional Sales
The dashboard compares sales performance across different regions.

### Category Profitability
Profit contribution and profit margins are analyzed across Furniture,
Office Supplies, and Technology.

### Product Performance
The dashboard identifies products with high sales and profit and highlights
products with weaker profitability.

### Sales vs Profit
A scatter plot is used to examine the relationship between product sales
and profit.
